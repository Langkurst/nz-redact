How it works

  1. Paste text into step 1, or open a .txt or .csv file. Each detail it finds is highlighted in the text and listed under Found. Untick a detail to leave it in.
  2. Copy the redacted text from step 2. Each detail is replaced by a numbered placeholder such as [IRD_1]. The same detail always gets the same placeholder, so the AI can still tell people and accounts apart.
  3. Paste the AI's answer into step 3. The placeholders turn back into the real details, ready to copy.

What it finds

NZ Redact looks for eleven kinds of New Zealand detail. Numbers that have a check digit are only flagged when the check digit is right, so order numbers and prices are left alone.

Accuracy

NZ Redact was tested blind on two sets of 30 New Zealand documents: emails, payroll notes, spreadsheet rows and support tickets. Both sets were written by an AI model that was never shown the rules. For set 1 it wrote a script that fills each document with generated numbers and records every detail it puts in. For set 2 it wrote the documents and marked up the names itself. Text written by people is often messier, so treat these figures as a guide. These are the results as measured, including what it misses.

A name marked possible is a guess from the word itself, for example a common first name in a sentence. It is ticked, so it is removed, and you can untick it.

The results for the first set were known before the work on version 1.1 started. The rules were not tuned on its documents, but that is why the second set was written. It was written after the 1.1 rules were finished, by an AI model that had not seen them, and it contains no numbers, emails or addresses, only names and look-alike words.

While the rules were being built, a separate set of 80 documents was used to find gaps. On that set it found 0% of numbers, dates, emails, phones and addresses, and 0% of names. All three sets are in the repository, and npm run eval measures them again.

What it does not catch

  • About a third of names. Most names are now found, but the ones missed are mostly names in ordinary sentences that are not common first names. Always read the redacted copy before you paste it, and use Remove this too for anything it missed.
  • Health details, such as a diagnosis written in words.
  • Numbers split across lines, or written in words.
  • Company GST numbers and company bank accounts use the same check digits as personal ones, so they are removed too. That is on purpose: removing too much is safer than too little.

Use in code

The rules are a single JavaScript file with no dependencies. It works in the browser and in Node.js. Copy src/nz-redact.js from GitHub, where every rule and test is published under the MIT licence.

// Find the details and make the redacted copy
const found = NZRedact.scan(text);
const { text: safe, map } = NZRedact.redact(text, found);

// Later: put the details back into the AI's answer
const { text: answer } = NZRedact.restore(aiReply, map);

Privacy

Nothing you paste is sent anywhere. The page's security policy blocks it from connecting to any server, and once it has loaded it also works offline.

There are no cookies and no tracking. If you pick a light or dark theme, that choice is saved in your own browser. The Ko-fi link opens Ko-fi's own site.
