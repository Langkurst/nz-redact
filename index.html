Take the personal details out before it goes into AI.

Paste an email, a note or a spreadsheet. NZ Redact swaps IRD, NHI, bank, card, licence and passport numbers, phone numbers, emails, dates of birth, street addresses and labelled names for placeholders such as [IRD_1]. When the AI answers, paste the answer back and the real details return.

  • Nothing is sent. The page is blocked from connecting to anything, and works offline.
  • Real checks. IRD, NHI and bank numbers must pass their official check digit.
  • Open rules. Every rule and test is on GitHub under the MIT licence.

How it works

Three steps, all on your device

  1. 01

    Paste

    Paste text or drop a file. Every detail it finds is marked in place, grouped on the right, and can be switched off.

  2. 02

    Copy the redacted text

    Each detail becomes a numbered placeholder. The same number always gets the same placeholder, so the AI can still follow who is who.

  3. 03

    Put the details back

    Paste the AI's answer into step 3. The placeholders turn back into the real details, ready to copy.

What it does not catch

  • Most names written in ordinary sentences. It finds names after a label such as Name, Patient or Dear, and in a name column. Read the redacted copy before you paste it.
  • Health details, such as a diagnosis written in words.
  • Numbers split across lines, or written in words.
  • Company GST numbers and company bank accounts use the same check digits as personal ones, so they are removed too. That is on purpose: removing too much is safer than too little.

Use in code

One file, no dependencies

The rules are a single JavaScript file that works in the browser and in Node.js. Copy src/nz-redact.js from GitHub.

// Find the details and make the redacted copy
const found = NZRedact.scan(text);
const { text: safe, map } = NZRedact.redact(text, found);

// Later: put the details back into the AI's answer
const { text: answer } = NZRedact.restore(aiReply, map);
